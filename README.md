# Slashr

Slashr is a Letterboxd-inspired app focused on horror games.  
The goal is to let users discover, track, and review horror games in a simple and social way.

The app uses an IMDb-based database to fetch and display game-related data.

## ✨ Current Status

The following features are already implemented:

- 🏠 Dashboard / Home Page  
- 🔎 Search functionality for horror games  
- 📊 Basic UI for game listings  

---

## 🚧 Planned Features

Development was paused before implementing authentication. Planned features include:

- 🔐 User authentication (login / signup)
- 📚 Personal game logging (played / playing / backlog)
- ⭐ Ratings and reviews
- 📅 Game tracking lists
- 👤 User profile pages

---

## 💡 Concept

Slashr aims to become a central hub for horror game enthusiasts to:

- Discover new horror games  
- Track their personal gaming history  
- Rate and review experiences  
- Build curated lists of games  

---

## ⚠️ Status

This project is currently **unfinished / work in progress** and serves as a prototype.
